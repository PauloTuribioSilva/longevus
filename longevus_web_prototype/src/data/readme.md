# Dados e contratos do frontend

Este diretório foi criado para separar a camada de dados de apresentação e deixar o projeto pronto para a equipe de backend.

## Estrutura

- `backend-contract.js`: contrato de integração e exemplos de payload.
- `emptyState.js`: estado inicial vazio para o frontend, sem dados artificiais.

## Regras

- Não armazenar dados reais de pacientes.
- Não criar registros fictícios de pessoas no frontend.
- Usar este diretório como referência para integração real.
- Manter o app em estado vazio até que a API esteja disponível.
